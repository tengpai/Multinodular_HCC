# Historical code retained for traceability

These files predate the current max-H2 manuscript analysis. `habitat/` uses old
max-H1; `fusion_model/` includes earlier fusion, subgroup and exploratory
NRI/IDI/time-dependent AUC analyses. They are not the current reproduction entry
points. Outputs or model labels from them must not be substituted into current
tables. Their code is retained unchanged, with the original public path
anonymization. `requirements_historical.txt` records the old repository text; it
is not the verified dependency specification for the current release.

Use `../current_analysis/` and the root documentation for the current pipeline.
